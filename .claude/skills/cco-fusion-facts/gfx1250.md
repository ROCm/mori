# gfx1250 facts

No fact has been measured on gfx1250 for these operators yet.

Do not carry gfx950 numbers or ISA rules over. The things they depend on can differ
on gfx1250: the cache-control bits on stores (`sc0 sc1`), the cache maintenance
instructions a release or an acquire emits (`buffer_wbl2`, `buffer_inv`), the number of
copy engines and queues, and the link bandwidth.

Until a fact here is measured:

- treat every hardware number as unknown, and label any claim borrowed from gfx950
  `inferred`;
- check the emitted ISA for the actual instructions before applying an ISA rule;
- add facts with the IDs `G1250-<GROUP>-<NN>`, following the rules in
  [SKILL.md](SKILL.md).
